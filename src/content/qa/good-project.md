**Sample answer — placeholder content.**

Look for a problem you keep running into, then build the smallest thing that makes it less annoying.

Three questions help:

- Would I use this even if nobody else saw it?
- Can I make a useful first version in a weekend?
- Will I learn something I’m curious about?

If the answer is yes to all three, it’s probably worth an experiment.
